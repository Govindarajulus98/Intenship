# Distributed Task Processing System

A Distributed Task Processing System built using Python sockets, threading, queue scheduling, and Flask dashboard.

## Features

- Multiple Clients
- Dynamic Workers
- Queue Scheduling
- Live Dashboard
- Worker Auto Termination
- Waiting Queue Visualization
- Task History Tracking

## Technologies Used

- Python
- Flask
- Socket Programming
- Threading
- Queue
- HTML/CSS

## Run Project

Install Flask:

pip install flask

Run dashboard:

python dashboard.py

Open browser:

http://127.0.0.1:8000
